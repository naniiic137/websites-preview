## Overview

This repository is a portfolio of fully functional, production-quality website demos. Each project is a **single self-contained HTML file** — all CSS and JavaScript is inlined, meaning you can open any file directly in a browser with zero setup. The main `index.html` serves as a landing page that links to all 9 projects with filtering, dark/light theme toggle, and a contact form.

## Tech Stack

Every project uses the same core technologies:

| Technology | Usage |
|---|---|
| **HTML5** | Semantic markup, accessibility attributes, `<noscript>` fallbacks |
| **CSS3** | Custom properties (variables), Grid, Flexbox, animations, `clamp()`, `backdrop-filter`, `prefers-reduced-motion` |
| **Vanilla JavaScript** | DOM manipulation, IntersectionObserver, event delegation, localStorage, form validation, Canvas API |

**No frameworks. No libraries. No dependencies. No build step.**

Each project is a single `.html` file with all CSS and JS inlined.

## Features Across All Projects

- **Fully Responsive** — Breakpoints at 1024px, 768px, and 480px with mobile-first considerations, hamburger menus, and touch-friendly 44px minimum tap targets
- **Dark/Light Themes** — Several projects include full theme toggling with CSS custom property swapping and localStorage persistence
- **Scroll Animations** — IntersectionObserver-powered reveal effects (fade-up, fade-in, slide-left, slide-right, scale-in) with staggered delays
- **Form Validation** — Contact, booking, RSVP, and reservation forms all include inline error messages and success states
- **Accessibility** — ARIA labels on interactive elements, `prefers-reduced-motion` support, keyboard navigation, focus-visible styles, `<noscript>` fallbacks
- **Performance** — Lazy-loaded images, passive scroll listeners, CSS-only animations where possible, zero external dependencies
- **Self-Contained** — Every project is a single HTML file — no build tools, no node_modules, no CDN dependencies
